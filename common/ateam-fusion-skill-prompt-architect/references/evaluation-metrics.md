# Evaluation Metrics for Fusion Skill Prompt Architect

Use these metrics to assess whether prompts generated with this skill are genuinely useful and performant for DMA A-Team use.

## 1) Usefulness metrics

### `task_success_rate`

- Definition: Fraction of prompt runs that produce an implementation-usable skill artifact.
- Formula: `successful_runs / total_runs`
- Target: `>= 0.90`

### `first_pass_acceptance_rate`

- Definition: Fraction of outputs accepted by reviewer without major rework.
- Formula: `first_pass_accepted / total_submissions`
- Target: `>= 0.80`

### `coverage_rate`

- Definition: Required output sections present divided by required sections total.
- Formula: `sections_present / sections_required`
- Target: `>= 0.95`

### `fusion_fidelity_rate`

- Definition: Verified Fusion claims divided by total Fusion claims.
- Formula: `verified_claims / total_claims`
- Target: `>= 0.95`

### `implementation_coverage_rate`

- Definition: Coverage of required implementation pillars in generated outputs.
- Formula: `implementation_pillars_covered / implementation_pillars_required`
- Target: `>= 0.95`

## 2) Performance metrics

### `p95_latency_ms`

- Definition: 95th percentile generation time in milliseconds.
- Target: `<= 3000`

### `avg_iteration_count`

- Definition: Mean number of revision loops required to pass quality gates.
- Target: `<= 2.0`

### `accepted_per_1k_tokens`

- Definition: Accepted artifacts normalized by generated token volume.
- Formula: `(accepted_artifacts / generated_tokens) * 1000`
- Target: team-defined baseline + trend improvement over time.

### `consistency_rate`

- Definition: Proportion of repeated runs (same input) that preserve required structure and key decisions.
- Formula: `consistent_runs / repeated_runs`
- Target: `>= 0.90`

## 3) Reliability and safety metrics

### `hallucination_rate`

- Definition: Unsupported key technical claims divided by total key technical claims.
- Formula: `unsupported_claims / total_key_claims`
- Target: `<= 0.02`

## 4) Suggested quality gates

Minimum gate to promote a prompt for organizational reuse:

- `task_success_rate >= 0.90`
- `fusion_fidelity_rate >= 0.95`
- `implementation_coverage_rate >= 0.95`
- `hallucination_rate <= 0.02`
- `p95_latency_ms <= 3000`
- `avg_iteration_count <= 2.0`

If any gate fails, revise prompt and rerun evaluation.

## 5) Synthetic benchmark recommendation

Use a 24-prompt benchmark generated by `scripts/generate_synthetic_prompts.py` with balanced coverage:

- 8 Golden path scenarios
- 8 Edge-case stress scenarios
- 8 Adversarial or ambiguity-heavy scenarios

Generate evaluation params from those prompts using:

```bash
python3 agent-skills-fusion/fusion-skill-prompt-architect/scripts/build_synthetic_eval_params.py \
  --manifest <synthetic_manifest.json> \
  --output <synthetic_eval_params.json>
```

Then execute:

```bash
python3 agent-skills-fusion/fusion-skill-prompt-architect/scripts/evaluate_prompt_skill_with_report.py \
  --params <synthetic_eval_params.json> \
  --manifest <synthetic_prompt_manifest.json> \
  --scorecard-output <synthetic_scorecard.json> \
  --html-output <synthetic_scorecard_report.html>
```

Policy: every operational evaluation run must produce both JSON and browser HTML report artifacts.
