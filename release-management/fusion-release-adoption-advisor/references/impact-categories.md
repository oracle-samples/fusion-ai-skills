# Impact Classification Guidance

## Operational Efficiency
Features that reduce manual work, approvals, reconciliation effort, or repetitive activities.

## AI or Automation
Features involving intelligent recommendations, predictive analysis, generative AI, automation, or autonomous workflows.

## Compliance or Audit
Enhancements supporting regulatory reporting, auditability, controls, or governance.

## User Experience Improvement
Improvements focused on usability, navigation, mobile experience, accessibility, or reduced clicks.

## Integration Enhancement
Changes impacting APIs, data synchronization, external systems, or integration architecture.

## Reporting and Analytics
Capabilities improving dashboards, KPIs, OTBI, analytics, or embedded insights.

## Security and Governance
Changes related to privileges, segregation of duties, authentication, or data access.
