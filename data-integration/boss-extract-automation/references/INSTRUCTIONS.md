# Instructions for Using the BOSS Extract Automation Skill

## Minimum Working Setup
1. Install dependencies exactly with `python -m pip install -r ai_skills/boss_extract_automation/requirements.txt`.
2. Set the required environment variables in `ai_skills/boss_extract_automation/assets/.env`.
3. Set the default mapping in `ai_skills/boss_extract_automation/assets/mapping.json`.
4. Set non-secret runtime defaults in `ai_skills/boss_extract_automation/assets/extract_config.json`.
5. Verify the wallet directory exists and the output directory is writable.
6. Run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py preflight`.
5. Expected success output: JSON containing `"status": "ok"`.

## Basic Usage
- **Preflight only**: `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py preflight`
- **Offline validation with fixture**: set `metadata_source: "fixture"` and `metadata_fixture` in `ai_skills/boss_extract_automation/assets/extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py validate-view`
- **Validation with mapping + catalog**: set `metadata_source: "mapping"` and `catalog_csv_path` in `ai_skills/boss_extract_automation/assets/extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py validate-view`
- **Validation with DB**: set `metadata_source: "db"` in `ai_skills/boss_extract_automation/assets/extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py validate-view`
- **Dry run**: set `dry_run: true` and choose the desired metadata source in `ai_skills/boss_extract_automation/assets/extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py run`
- **Run an Extract**: set the target mapping/defaults in `mapping.json` and `extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py run`
- **Customize Scheduling**: update `frequency`, `frequency_hourly_interval`, `frequency_days_in_week`, `start_time`, and related fields in `extract_config.json`
- **Monitor existing work**: set `schedule_id` or `job_request_id` in `extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py monitor`
- **Download existing files**: set `job_request_id` in `extract_config.json`, then run `python ai_skills/boss_extract_automation/scripts/GenerateTEMS_Extracts.py download`

## Metadata Configuration
- `metadata_source` supports `auto`, `fixture`, `mapping`, and `db`.
- `metadata_fixture` is only required when `metadata_source` is `fixture`.
- `catalog_csv_path` is used with `metadata_source: "mapping"` and points to the catalog CSV generated by `ExtractCatalog.py`.
- In `auto` mode, the script tries fixture first (if present), then mapping + catalog CSV, and finally falls back to DB.
- DB preflight checks are required when `metadata_source` is `db` or when `require_db` is explicitly set to `true`.

## Agent Integration
- Load this skill’s files into your agent’s knowledge base.
- When triggered, parse inputs and map to script arguments.
- Execute the script via CLI tools, capture outputs, and report statuses.
- For errors, reference `CHECKLISTS.md` for troubleshooting steps.

## Notes
- Missing `oracledb` now fails lazily with an actionable install command instead of crashing at import time.
- In restricted environments, use `metadata_source: "fixture"` with `metadata_fixture`, or `metadata_source: "mapping"` with `catalog_csv_path`, to operate without live DB metadata lookup.
- JSON output is intended for both humans and automation.
